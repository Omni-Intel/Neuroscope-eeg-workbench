# 自动报告样例

两份 Word 均使用**人为合成的两通道信号**，只用于检查分析流程、图表和排版；不是任何设备的实测结果。

- `SSVEP-模拟数据报告.docx`：四个已知频率，各 3 次；不是正式默认 20 次。
- `运动想象-模拟数据报告.docx`：左手、右手、静息各 3 次，信号人为设置了对侧功率下降；不是正式默认 30 次。

正式报告由桌面程序按每次实际记录生成，不能将这里的准确率或 ERD 当成设备性能。

报告按主题放置结果表、证据图和对应解释。示例中 SSVEP 为 8 页、6 张图，运动想象为 10 页、8 张图；实际页数随通道、测量和实验分组数量变化。两份示例均无实际阻抗测量，报告明确说明该项不可评价。

# Omni 采集与 EDF 保存

OmniBCI 0.2.0 的已验证 ESP32 / STM32 记录可自动准备 EDF 参数，无需为了保存数据先填写头皮电极映射。不区分空载或人体模式，不猜测实际接线。

## 操作

1. 在“实验准备”选择公司 OmniBCI、实际设备类型和地址，连接并检查数据。
2. 状态区显示实际样本、通道数及 EDF 参数准备情况。需要记录参考接法或环境工频时，断开后点击“填写 / 保存 Omni 采集信息”；未知可以留空。保存位置随用户配置目录，后续可复用，旧文件会备份。
3. 完整采集结束后，原始数据保存在 `Records`；EDF 与规范交付文件保存在 `data`，报告保存在 `Reports`。查看“记录与报告”中的分别处理结果。
4. 已有记录可点击“为已有记录补导出 EDF”，选择对应 `run.json`。不必重采；已有交付包不静默覆盖。

## 参数来源与边界

| 信息 | 来源或处理方式 |
| --- | --- |
| 设备类型、通道数、单位、增益、模式、SDK 版本 | 实际记录的 SDK 元数据及前端配置读回；仅对已核对的 0.2.0 契约自动处理 |
| 通道名称 | 沿用采集记录的名称；CH1～CH32 是合法存储名称，不被自动解释为头皮位置 |
| 参考接法、工频 | 优先保留已填写信息；未知使用 `n/a` 并在交付 JSON 中说明是未记录，不代表已验证不存在 |
| 软件滤波 | 默认存储 SDK 原样数据，未做 NeuroScope 软件滤波；不推断硬件滤波配置 |
| 标称范围 | SDK 的 4.5 V 参考电压、实际逐通道增益、24 位有符号 ADC 换算；向外取整以适配 EDF 头，来源写入交付 JSON，不等于硬件校准 |
| 同步 | 沿用原记录的许可及对齐依据；软件估计不是物理刺激时刻，不因自动导出而升级同步可信度 |

**EDF 是 16 位编码，不是原始浮点样本的无损副本。**程序回读检查样本数、采样率、范围和误差，并在 `Records/<记录>/delivery/edf_encoding.json` 保存各通道量化步长和最大误差。增益 24 时本实现的完整标称范围对应约 5.722 μV/步；SDK 的原始浮点值及 ADC 计数继续保留在 `raw` 中，NeuroScope 报告仍使用原始记录。

未知电极映射不阻止 EDF 导出，但专项 SSVEP 分析仍需实际电极和参考信息。保存本页的采集信息不会自动确认专项分析配置。BIDS 校验通过只表示本次格式检查通过，不表示参考接法、脑电质量或同步已经验证。

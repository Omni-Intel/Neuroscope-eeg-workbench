# NeuroScope 高刷新桌面控制台设计

## 目标

新增基于 PySide6 和 pyqtgraph 的 Windows 桌面控制台，作为 NeuroScope 的主要采集入口。它需要稳定显示 32 通道滚动 EEG，默认目标 30 FPS，并允许用户切换至 60 FPS。

Streamlit 保留为备用分析工作台，不再承担主要实时采集显示职责。

## 性能目标

- 默认波形刷新率：30 FPS；
- 可选刷新率：20、30、60 FPS；
- 30 FPS 模式下，32 通道、4 秒窗口连续运行时界面保持响应；
- 实际 FPS、累计样本数、缓冲样本数和最近数据年龄持续可见；
- 实际 FPS 低于目标的 80% 时警告，低于 50% 时显示异常；
- 显示刷新不得阻塞设备采集线程；
- 显示降采样不得改写原始缓冲、记录数据或 decoder 输入。

60 FPS 是可选性能模式。如果采集电脑无法维持目标，控制台显示实际 FPS，不静默声称已达到 60 FPS。

## 架构

### 采集线程

继续使用统一 `EEGSource` 和 `SessionController`。设备线程以原始采样率读取数据并写入环形缓冲，不执行绘图。

BrainCo 使用官方 32 通道顺序和现有专用显示预处理。Neuracle 继续使用原有采集实现和通道元数据，不进入 BrainCo 分支。

### 界面线程

Qt 主线程只负责读取缓冲快照和更新已有控件：

- 通过 `QTimer` 按 20、30 或 60 FPS 触发波形刷新；
- 32 条 `PlotDataItem` 在启动时创建一次；
- 每帧只调用 `setData()`，不重建坐标轴或图形对象；
- 关闭抗锯齿并启用 pyqtgraph 的可视区域裁剪和自动降采样；
- 每通道独立稳健缩放，异常电极不会压扁其他通道。

### 分频分析

不同任务使用独立定时器：

- 波形：20、30 或 60 FPS；
- 连接状态和数据新鲜度：10 FPS；
- 频谱和信号质量：4 FPS；
- 范式 decoder：2–4 FPS。

分析异常不停止采集或波形刷新。

## 界面

主窗口包含：

- 左侧：数据源、范式、采样率、通道数、设备地址、`oi-mi` 路径、启动和停止；
- 顶部：连接状态、数据源、采样率、目标 FPS、实际 FPS、最近数据年龄；
- 中央：32 通道四秒滚动波形；
- 下方标签：频谱、信号质量、范式分析、实验记录；
- 状态栏：累计样本、缓冲样本、数据块数量和错误信息。

BrainCo 连接参数只在选择 BrainCo 时出现；Neuracle JellyFish 参数只在选择 Neuracle 时出现。

## 中文显示

Qt 全局字体优先使用 `Microsoft YaHei UI`，找不到时使用 Windows 系统默认中文字体。实时控制台不使用 Matplotlib 绘制主界面，因此不再出现 DejaVu Sans 缺少中文字形的警告。

## 数据与分析

- BrainCo 波形使用去漂移和 1–45 Hz 带通显示副本；
- Neuracle 波形保持现有逻辑；
- 频谱、质量和 decoder 复用现有模块；
- 视觉任务继续独立记录图像类别、目标是否出现和是否报告看见；
- 未标定 decoder 继续明确标记为即时基线估计。

## 依赖与启动

新增桌面可选依赖：

- `PySide6`；
- `pyqtgraph`。

提供：

- Python 命令：`python -m neuroscope_eeg.desktop.app`；
- 安装命令：`pip install ".[desktop]"`；
- Windows 双击脚本：`启动-NeuroScope桌面控制台.bat`。

BrainCo 仍需安装 `requirements-brainco.txt`；Neuracle 仍需 JellyFish 实时转发。

## 错误处理

- 尚无数据：显示已收到样本数和目标样本数；
- 数据超过 2 秒未更新：波形保持但显示红色“数据已停止更新”；
- 设备异常：停止对应会话，不退出主程序；
- 分析异常：只影响对应分析卡片；
- FPS 不达标：显示实际值并允许切换到 30 或 20 FPS；
- 关闭窗口：停止设备流和后台线程后退出。

## 测试与验收

自动化验证：

- Qt 界面模块可在无显示环境导入；
- 刷新率选择正确映射为定时器间隔；
- 32 条曲线只创建一次，连续刷新复用对象；
- FPS 统计和告警级别正确；
- 数据停止更新提示正确；
- BrainCo 官方通道顺序保持；
- Neuracle 采集和通道测试保持通过；
- 原有 18 项测试继续通过。

本地验证使用模拟和回放数据。BrainCo 与 Neuracle 的真实性能和设备关闭流程需要在 Windows 采集电脑上最终验收。

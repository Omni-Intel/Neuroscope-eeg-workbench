# BrainCo 实时显示与信号质量修复设计

## 目标

修复 BrainCo 32 通道数据在 NeuroScope 中波形被异常通道压扁、质量指标失真、通道名称错位以及无法判断数据是否持续更新的问题。

本补丁只作用于 BrainCo。博睿康 Neuracle 的通道顺序、采集、显示、质量分析和范式分析逻辑保持不变。

## 设备隔离

以统一数据源元数据中的 `source_type == "brainco"` 作为唯一分支条件：

- BrainCo 使用官方 32 通道顺序；
- BrainCo 使用专用显示预处理和逐通道缩放；
- BrainCo 的信号质量基于显示预处理后的数据；
- BrainCo decoder 使用去漂移和带限后的数据；
- 其他数据源继续使用当前逻辑。

禁止通过通道数等间接条件识别设备，避免 32 通道 Neuracle 被误处理。

## BrainCo 通道顺序

采用 SDK 公布的顺序：

`FP1, FP2, F3, F4, F7, F8, Fz, C3, C4, Cz, P3, P4, P7, P8, Pz, O1, O2, T7, T8, FC1, FC2, FC5, FC6, CP1, CP2, CP5, CP6, FT9, FT10, TP9, TP10, IO`

当用户选择少于 32 个通道时使用该顺序的前 N 个；最多 32 个。Neuracle 继续使用原 64 通道布局。

## BrainCo 显示预处理

只对 BrainCo 的实时显示副本执行：

1. 每通道线性去趋势；
2. 1–45 Hz 带通；
3. 50 Hz 陷波仅在奈奎斯特频率允许时应用；
4. 每通道使用自身的稳健幅度独立缩放后绘图。

显示副本不改写环形缓冲中的原始数据，记录和诊断仍可保留原始样本。频谱、质量指标和即时基线 decoder 使用带限数据，避免直流漂移主导结果。

不猜测额外的单位换算系数。若强脑 SDK 或固件输出单位仍需确认，界面保留明确提示。

## 实时状态

采集控制器记录：

- 已接收的非空数据块数量；
- 已接收样本总数；
- 最近一次收到非空数据的时间；
- 当前缓冲样本数量。

等待页面显示已收到样本数与目标样本数。收到数据后，页面显示最近数据年龄和累计样本数，使“显示被压扁”和“数据已停止更新”可以直接区分。

刷新间隔从约 0.8 秒缩短到约 0.4 秒。Streamlit 仍是浏览器仪表盘，不承诺示波器级帧率。

## 信号质量

BrainCo 质量页使用去趋势、带通后的数据；Neuracle 继续使用原始输入和原有阈值。质量图注明 BrainCo 已经过显示预处理。

逐通道缩放只用于波形可见性，不会把异常通道标记为正常。异常通道仍由质量模块独立报告。

## 验证

- BrainCo 元数据严格等于官方 32 通道顺序；
- BrainCo 少通道配置使用官方顺序前缀；
- Neuracle 默认 64 通道顺序不变；
- BrainCo 异常大漂移通道不会压扁其他通道的显示；
- BrainCo 预处理输出有限值且形状不变；
- 非 BrainCo 数据不经过 BrainCo 专用预处理；
- 控制器正确累计非空块、样本数和最新数据时间；
- 全部现有测试和 Streamlit 启动检查继续通过。

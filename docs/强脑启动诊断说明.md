# 强脑一键采集检测（SDK 2.1.2）

版本标识：`2026-10-31-layout-startup-v3`。针对 2026-10-31 真机日志中“设备已就绪，但配置应答缺少 mode，SDK 报 expected 1, got 0”的情况增加配置回读路径。正式软件的 SDK 2.1.2 连接已采用配置回读路径，同时修复 33 列缓冲区解析；SDK 文件不变。

## 现场操作

1. 将更新后的 `NeuroScope-portable` 复制到采集电脑，避免误用桌面上的旧包。
2. 退出其他采集程序的设备连接，让目标帽子开机联网。
3. 双击 `BrainCo-diagnostic-all.bat`，确认窗口版本标识为上述 v3。
4. 等待完成，带回窗口显示的 `logs/brainco-check-时间.zip`。默认每条路径最多 180 秒，最坏五条路径约 15 分钟；通常失败会提前返回，收到符合条件的数据就停止后续路径。

## 自动执行的路径

1. `production`：使用与正式桌面程序相同的修复路径，优先验证采集。成功后不再尝试后续路径。
2. `unified`：标准 SDK 一键启动，保留基线结果。
3. `verified-config`：连接 → 停止阻抗检测和 EEG → 独立读取当前配置。如果已是指定采样率、GAIN_6、NORMAL，跳过配置写入并直接启动 EEG。如果不符合，设置配置，再独立查询确认后启动。
4. `stepwise`：原有分步检查，定位格式协商、配置或启动的错误。
5. `legacy-mode`：调用 SDK 的正常 EEG 模式入口。它不额外调用 negotiate_eeg_stream，但 start_data_stream 本身仍执行 SDK 内置握手；不能声称完全绕过格式协商或序列号要求。

每条路径使用独立子进程，首次发现的设备地址固定用于后续尝试。超时、进程崩溃或断开失败时停止整组检查；应先重启帽子再重新连接。

## 配置回读如何判断

- 严格按本次请求 msgId 匹配配置回复；不使用旧回复或无关消息作为确认。
- 优先使用 SDK 返回的请求 ID；接口不返回 ID 时，从同一次调用的 SDK 发送日志取得唯一 ID。无法确定 ID 时失败，不猜测。
- 只有设置配置时报出精确错误 `EEG mode acknowledgement mismatch: expected 1, got 0`，且同一请求的配置应答缺少 mode 字段时，才进入独立回读确认。原始异常和应答完整保留。
- 独立读取的频率、增益、信号源必须与请求一致，才能发送启动命令。明确错误的 mode、配置不符、无法回读、其他异常均失败。
- 启动命令的错误不被此兼容处理吞掉；仍须实际收到持续 EEG 才能通过。

这是受证据约束的诊断路径，尚待真机验证；不修改 SDK，不伪造序列号，不发送自编协议报文，不自动刷固件。

## 数据与文件验证

启动后默认观察 30 秒新数据，逐秒记录新增样本数、累计样本数、回调样本数和数据包数。要求 32 通道、有限值、超过 2 秒的观察断流不通过、平均读取速率位于配置采样率的 80%～120%。主机观测速率不能代替硬件时钟精度、丢包率或重复样本验证。

实际样本保存到各路径目录的 `eeg-preview.npz`，保存后重新打开比对数组和配置采样率，并记录 SHA256。`eeg` 为通道×样本数组；`configured_sfreq` 是配置采样率。该短时文件不是正式实验的 EDF/BIDS 导出。无效值及错误通道数的数据不会纳入有效样本，异常前已收集的有效样本尽量保存。

包内包括 summary.json、每条路径的 result.json 和日志；配置回读证据记录在 config_evidence。完成观察时另写 observation.json，数据未通过速率检查时也保留统计。诊断包可能包含真实脑电样本，分享包时也会分享这些样本。

成功只表示该路径短时收数与诊断文件保存通过，不证明生理信号质量、长时间采集、正式导出或范式打标正常。脚本不发送 Marker，关闭 TriggerBox 同步；正式实验仍需验收。

默认自动扫描、32 通道、250 Hz、GAIN_6、NORMAL。多帽环境请指定地址，或只保留目标帽子可发现。

```powershell
# 便携版终端中运行，观察 60 秒
.\BrainCo-diagnostic-all.bat --seconds 60
# 单独运行新增路径
.\BrainCo-diagnostic-verified-config.bat
# 源码环境
.\.venv\Scripts\python.exe -B -m neuroscope_eeg.diagnostics.brainco_startup --mode all
```

支持 --seconds 10～120、--sfreq 250/500/1000/2000；手动连接需同时传入 --host 实际IP --port 实际端口。退出码 0：短时数据与保存检查通过；1：未通过；2：异常退出或清理状态不确定。

v3 增加 device_timestamps 到诊断 NPZ，保留 SDK 暴露的设备时间戳；其单位和精度限制详见《强脑33列布局验证.md》。第一列不再作为 EEG 通道，也不参与样本去重。

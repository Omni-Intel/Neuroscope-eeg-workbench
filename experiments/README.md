# 本地实验信息

在桌面选择范式后点击“建立 / 编辑实验信息”，为该范式保存 `<范式标识>/metadata.toml`。
三个顶层字段为 full_name、unique_name、description，不包含被试信息。
unique_name 使用 1–6 位大写字母和有效建立日期，保存后保持稳定，不按每次采集改名。
用户已指定 SSVEP 使用 SSVEP-20261030、运动想象使用 MI-20261030；选择这两种范式自动填入代码及唯一名称。该本地设置不代表已验证外部平台登记。
其他范式不预填编号。模拟身份仅用于流程验证。
完整使用与限制见 ../docs/规范实施与使用.md。
